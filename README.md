# 회의록

설치 없이 브라우저에서 바로 쓰는 **실시간 회의록 작성 도구**입니다.
파일 하나(`index.html`)로 동작하며, 모든 데이터는 사용자의 브라우저(localStorage)에만 저장됩니다. **서버로 전송되는 것이 아무것도 없습니다.**

회의를 따라가며 받아 적을 때 키보드에서 손을 떼지 않는 데 초점을 맞췄습니다.

- 화자 전환은 `Alt+숫자` 한 번 — 한 번 고르면 유지되므로 사람이 바뀔 때만 누릅니다.
- 기록은 `Enter` 한 번 — 한글(IME) 조합 중에도 Enter를 두 번 누를 필요가 없습니다.
- 결정·조치·질의·안건·비공개는 줄 맨 앞 문장부호로 표시 — 한/영 전환이 필요 없습니다.

## 시작하기

1. `index.html`을 브라우저로 열거나, GitHub Pages로 배포한 주소에 접속합니다.
2. 참석자를 한 줄에 한 명씩 입력하고 **회의 시작**을 누릅니다.
3. `Alt+숫자`로 화자를 고르고, 발언을 입력한 뒤 `Enter`.

자주 모이는 위원회·협의회는 명단을 **위원회**로 저장해 두면 다음 회의부터 불러오기 한 번으로 시작할 수 있습니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Alt` + `1~9`, `0`, `-`, `=` | 화자 1~12번 선택 (선택 유지) |
| `Alt` + `↑` / `↓` | 이전 / 다음 화자 |
| `Alt` + `` ` `` | 화자 미지정 (동시 발언 등) |
| `Enter` | 기록 (한글 조합 중에도 한 번만) |
| `Ctrl` + `Enter` | 강제 기록 — 한글 입력이 꼬였을 때 |
| `Shift` + `Enter` | 항목 안 줄바꿈 |
| `Ctrl` + `Alt` + 숫자 | 방금 기록한 항목의 화자 정정 |
| `Ctrl` + `Z` | 되돌리기 (입력창이 비어 있을 때) |
| `F4` / `F8` / `F9` | 도움말 / 내보내기 / 참석자·결석자 편집 |

## 줄 맨 앞 기호

| 기호 | 의미 |
|---|---|
| `!` 내용 | **결정사항** — 요약본·결정사항 표에 포함 |
| `*` 내용 | **조치사항** — `@담당자` `~기한` 병기 가능 (예: `* 계획서 재작성 @박서연 ~9/3`) |
| `?` 내용 | 질의 |
| `#` 제목 | **안건 전환** — 이후 발언이 이 안건 아래로 묶임 |
| `//` 내용 | 비공개 메모 — 서식 유지 복사·마크다운·텍스트·요약에서 제외 |
| `3` 내용 | 숫자+공백: 그 줄만 3번 참석자의 발언으로 기록 |
| `\` 내용 | 뒤따르는 기호를 무시하고 그대로 기록 |

`\`는 기호 뒤에도 쓸 수 있습니다. `! \3 학년 예산안 가결`처럼 쓰면 **결정사항으로 기록하면서 맨 앞 숫자는 화자 지정이 아니라 본문으로** 남습니다.
`2:1로 가결`처럼 콜론이 들어간 표현은 화자 지정으로 해석되지 않으니 그냥 쓰면 됩니다.

## 내보내기 (`F8`)

- **한글·워드 서식 유지 복사** — 표와 굵은 글씨가 그대로 붙습니다 (추천)
- 마크다운 / 일반 텍스트 / 요약
- **`.json` 저장** — 이 앱에서 다시 불러와 이어 쓸 수 있는 원본 백업

> `//` 비공개 메모는 서식 유지 복사·마크다운·텍스트·요약에서 제외됩니다.
> 다만 **`.json` 저장에는 비공개 항목까지 그대로 담깁니다** — 이어 쓰기 위한 원본이기 때문입니다.
> 남에게 전달할 때는 `.json`이 아니라 위의 내보내기를 쓰세요.

회의 머리말의 종료 시각·소요 시간은 **공개된 마지막 발언** 기준으로 계산되므로,
회의가 끝난 뒤 남긴 비공개 메모 때문에 시간이 늘어나지 않습니다.

## 데이터 저장과 백업

- 회의록과 위원회 명단은 **이 브라우저의 localStorage에만** 저장됩니다. 브라우저의 "사이트 데이터 삭제" 시 함께 사라집니다.
- 발언은 입력하는 즉시 자동 저장되고, 머리말 오른쪽에 `저장됨 HH:MM`이 뜹니다. 저장에 실패하면 빨간 `저장 실패!`가 뜨고 **그 경고는 저절로 사라지지 않습니다.**
- 끝난 회의는 시작 화면의 **지난 회의**에 최근 20개까지 자동 보관됩니다. 21번째부터는 **가장 오래된 회의가 지워지기 전에 어떤 회의인지 알려 줍니다.** 위원회 명단은 40개까지 저장됩니다.
- 작성 중인 회의가 있을 때 지난 회의를 열거나 다른 `.json`을 불러오면, **현재 회의를 먼저 보관함에 넣은 뒤** 전환합니다.
- 중요한 회의는 `F8 → .json 저장`으로, 위원회 명단은 시작 화면의 **위원회 전체 내보내기**로 파일 백업을 권장합니다. 다른 PC로 옮길 때도 이 파일을 사용합니다.

## 브라우저

- Windows의 **Chrome / Edge / Whale** 최신 버전을 권장합니다.
- Firefox는 `Alt+숫자`가 브라우저 탭 전환과 충돌할 수 있습니다.
- 교실 프로젝터(1024px)나 브라우저 확대(125~150%)처럼 폭이 좁아져도 머리말이 한 줄로 유지되고 가로 스크롤이 생기지 않습니다.
- 300~500건 규모의 긴 회의에서도 `Enter` 기록과 `Alt+숫자` 화자 전환은 1ms 안팎으로 처리됩니다.

## 알려진 제한

- 화자 단축키는 12명까지 지원합니다(참석자 등록도 12명까지). 명단에서 빠졌지만 발언이 남아 있는 사람은 목록 끝에 보존되며, 이렇게 보존되는 인원까지 합쳐 24명이 상한입니다.
- **같은 회의록을 여러 탭에서 동시에 열지 마세요.** 두 탭은 같은 저장 공간을 쓰기 때문에 나중에 저장한 쪽이 상대를 덮어씁니다. 이 상황이 감지되면 머리말에 빨간 `다른 탭 충돌!`이 뜨고 안내창이 나타납니다.
- 개별 발언의 수정(✎)·삭제(✕)·화자 드롭다운은 **마우스를 올려야** 나타납니다. 키보드만 쓸 때는 `Alt+숫자`(다음 발언 화자), `Ctrl+Alt+숫자`(방금 기록한 발언 정정), `Ctrl+Z`(되돌리기)를 사용하세요.

## 직접 배포하기 (GitHub Pages)

1. 이 저장소를 fork 하거나 파일을 새 저장소에 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main` / `(root)`로 지정하고 저장합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소이름>/` 에서 접속할 수 있습니다.
