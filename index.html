서식 유지 복사는 표와 굵은 글씨가 그대로 한글에 들어갑니다(가장 추천). 비공개(//) 항목은 서식 유지 복사·마크다운·일반 텍스트·요약에서 제외됩니다. .json 저장은 이어 쓰기 위한 원본 백업이라 비공개 항목까지 그대로 담기므로 남에게 전달하는 용도로는 쓰지 마세요.

참석자 편집

한 줄에 한 명(최대 12명). 순서를 바꿔도 기존 기록의 화자는 이름 기준으로 따라갑니다. 명단에서 지운 사람에게 발언이 남아 있으면 자동으로 목록 끝에 보존됩니다.

도움말

Alt + 1~9, 0, -, =화자 1~12번 선택. 한 번 고르면 계속 유지되므로 사람이 바뀔 때만 누릅니다.
Alt + ↑ / ↓명단 순서대로 이전 / 다음 화자
Alt + `화자 미지정 (동시 발언·전원 등)
Enter기록. 한글 조합 중에도 한 번만 누르면 됩니다.
Ctrl + Enter강제 기록 — 한글 입력이 꼬였을 때의 비상 버튼
Shift + Enter한 항목 안에서 줄바꿈
Ctrl + Alt + 숫자방금 기록한 항목의 화자를 정정
Ctrl + Z되돌리기 (삭제·수정·화자변경 모두). 입력창에 글을 쓰는 중이면 평소처럼 타이핑 되돌리기로 동작합니다.
F4 / F8 / F9도움말 / 내보내기 / 참석자·결석자
위원회 저장명단을 위원회로 저장해 두면 다음 회의는 시작 화면에서 불러오기 한 번으로 끝납니다. 회의 중에는 F9 창 위쪽에서 저장·불러오기가 됩니다.
결석자시작 화면 또는 F9 창에서 입력. 모든 내보내기의 머리말에 표시됩니다.
자동 저장입력할 때마다 이 브라우저에 저장되고 오른쪽 위에 저장됨이 표시됩니다. 빨간 저장 실패!가 뜨면 저절로 사라지지 않으니, 바로 F8 → .json 저장으로 백업하세요.
탭은 하나만같은 회의록을 두 탭에서 열면 나중에 저장한 쪽이 상대를 덮어씁니다. 감지되면 다른 탭 충돌!이 표시됩니다.
